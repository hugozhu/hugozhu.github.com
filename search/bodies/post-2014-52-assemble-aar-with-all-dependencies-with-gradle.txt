Android Library项目中如果使用Android Gradle plugin打aar包，通过maven依赖的库，或者是local依赖的aar都不会包含在生成的aar包里，如果项目是发布一个SDK，为了方便开发者使用，我们倾向于生成一个包含所有依赖库以及.so等文件的aar包。
通过反复研究和测试，以下Gradle脚本能满足需求，如果需要对代码运行ProGuard混淆，则需要使用Gradle 2.1
方法是为项目增加一个sub project（如pkg_project）专门用于打包，该项目中build.gradle内容如下：
apply plugin: &#39;java&#39; version = 1.0 buildscript { repositories { mavenCentral() } dependencies { classpath &#39;com.android.tools.build:gradle:19.1.0&#39; } } repositories { mavenCentral() } dependencies { compile project(&#39;:&lt;your_library_project&gt;&#39;) //此处填写需要打包的Android Library Project name } task sync_jars() &lt;&lt; { //把所有依赖的.jar库都拷贝到build/aar/libs下 copy { into buildDir.getPath() +&#34;/aar/libs&#34; from configurations.compile.findAll { it.getName().endsWith(&#34;.jar&#34;) } } } task sync_aars(dependsOn:&#39;:&lt;your_library_project&gt;:assembleRelease&#39;) &lt;&lt; { //把所有依赖的.aar库里包含的classes.jar都拷贝到build/aar/libs下，并重命名以不被覆盖 def jar_name def aar_path def dest_dir = buildDir.getPath()+&#34;/aar&#34; configurations.compile.findAll { it.getName().endsWith(&#34;.aar&#34;) }.collect { aar_path = it.getPath() jar_name = &#34;libs/&#34;+it.getName().replace(&#34;.aar&#34;,&#34;.jar&#34;) copy { from zipTree(aar_path) into dest_dir include &#34;**/*&#34; rename &#39;classes.jar&#39;, jar_name } } } task fataar(dependsOn:[sync_aars, sync_jars]) &lt;&lt; { task (obfuse_classes_jar, type: proguard.gradle.ProGuardTask) { //把build/aar/libs/*.jar混淆后生成build/aar/classes.jar configuration &#34;proguard.cfg&#34; injars buildDir.getPath()+&#34;/aar/libs&#34; outjars buildDir.getPath()+&#34;/aar/classes.jar&#34; libraryjars &#34;${System.getProperty(&#39;java.home&#39;)}/lib/rt.jar&#34; libraryjars &#34;${System.getProperty(&#39;java.home&#39;)}/Contents/Classes/classes.jar&#34; libraryjars System.getenv(&#34;ANDROID_HOME&#34;)+&#34;/platforms/android-19/android.jar&#34; }.execute() task (gen_aar, type: Zip) { //把生成最终的aar包，注意libs目录需要被排除 def dest_dir = buildDir.getPath()+&#34;/aar/&#34; baseName = &#34;mysdk-all&#34; extension = &#34;aar&#34; destinationDir = file(buildDir.getPath()) from dest_dir exclude &#34;libs&#34; }.execute() } 最后就可以使用gradlew pkg_project:fataar来打包了
