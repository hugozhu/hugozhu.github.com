在大语言模型(LLM)快速发展的今天，我们面临一个核心挑战：如何让模型能够访问和利用实时、专业或私有的知识？纯粹依赖预训练的模型往往会出现知识过时、幻觉问题，或者无法回答特定领域的问题。这就是检索增强生成(Retrieval-Augmented Generation, RAG)技术应运而生的原因。
RAG通过将外部知识库的检索能力与LLM的生成能力相结合，为这个问题提供了一个优雅的解决方案。它不需要重新训练模型，就能让AI系统访问最新的、特定领域的知识，同时显著降低幻觉问题。本文将深入探讨RAG的核心原理、架构设计以及实际应用中的最佳实践。
RAG的核心思想 RAG的基本思想非常直观：在生成答案之前，先从知识库中检索相关信息，然后将这些信息作为上下文提供给LLM，让模型基于这些事实进行回答。
这个过程可以类比为开卷考试：传统的LLM就像闭卷考试，只能依赖记忆中的知识；而RAG系统则像开卷考试，可以查阅参考资料后再作答，答案自然更加准确和可靠。
RAG vs 其他方案 让我们先比较几种常见的知识增强方案：
方案 优势 劣势 适用场景 预训练 知识内化在模型中，推理速度快 知识固化，无法更新，成本高昂 通用知识 微调(Fine-tuning) 可以学习特定领域知识和风格 需要大量数据和计算资源，知识仍会过时 特定任务或领域 RAG 知识可实时更新，成本低，透明可解释 检索质量影响结果，增加延迟 动态知识、事实性回答 长上下文 简单直接，无需额外系统 成本高，注意力衰减，token限制 小规模文档 RAG的核心优势在于知识与模型的解耦：你可以随时更新知识库而无需重新训练模型，这使得系统具有极高的灵活性和可维护性。
RAG系统架构 一个完整的RAG系统通常包含以下几个核心组件：
graph LR A[用户查询] --&gt; B[查询处理] B --&gt; C[向量检索] C --&gt; D[知识库&lt;br/&gt;Vector DB] D --&gt; E[相关文档] E --&gt; F[上下文构建] B --&gt; F F --&gt; G[LLM生成] G --&gt; H[答案] I[文档源] --&gt; J[文档处理] J --&gt; K[文本分块] K --&gt; L[向量化] L --&gt; D 1. 文档索引流程 (Indexing Pipeline) 这是RAG系统的准备阶段，负责将原始文档转换为可检索的格式。
文档加载与预处理 from typing import List import re class DocumentLoader: &#34;&#34;&#34;文档加载器，支持多种格式&#34;&#34;&#34; def load_pdf(self, file_path: str) -&gt; str: &#34;&#34;&#34;加载PDF文档&#34;&#34;&#34; # 使用PyPDF2或pdfplumber import pdfplumber text = &#34;&#34; with pdfplumber.open(file_path) as pdf: for page in pdf.pages: text += page.extract_text() return text def load_markdown(self, file_path: str) -&gt; str: &#34;&#34;&#34;加载Markdown文档&#34;&#34;&#34; with open(file_path, &#39;r&#39;, encoding=&#39;utf-8&#39;) as f: return f.read() def preprocess(self, text: str) -&gt; str: &#34;&#34;&#34;文本预处理：清理、标准化&#34;&#34;&#34; # 移除多余空白 text = re.sub(r&#39;\s+&#39;, &#39; &#39;, text) # 移除特殊字符 text = re.sub(r&#39;[\x00-\x08\x0b-\x0c\x0e-\x1f\x7f-\x9f]&#39;, &#39;&#39;, text) return text.strip() 文本分块策略 文本分块(Chunking)是RAG系统中最关键的步骤之一。分块策略直接影响检索质量和生成效果。
class TextChunker: &#34;&#34;&#34;智能文本分块器&#34;&#34;&#34; def __init__(self, chunk_size: int = 512, chunk_overlap: int = 50): &#34;&#34;&#34; Args: chunk_size: 每个块的目标大小(tokens) chunk_overlap: 块之间的重叠大小，用于保持上下文连贯性 &#34;&#34;&#34; self.chunk_size = chunk_size self.chunk_overlap = chunk_overlap def chunk_by_tokens(self, text: str) -&gt; List[str]: &#34;&#34;&#34;基于token数量进行分块&#34;&#34;&#34; # 使用tokenizer计算token数量 from transformers import AutoTokenizer tokenizer = AutoTokenizer.from_pretrained(&#34;sentence-transformers/all-MiniLM-L6-v2&#34;) tokens = tokenizer.encode(text) chunks = [] start = 0 while start &lt; len(tokens): # 提取当前块 end = start + self.chunk_size chunk_tokens = tokens[start:end] # 解码为文本 chunk_text = tokenizer.decode(chunk_tokens, skip_special_tokens=True) chunks.append(chunk_text) # 移动到下一个块，考虑重叠 start += self.chunk_size - self.chunk_overlap return chunks def chunk_by_semantic(self, text: str) -&gt; List[str]: &#34;&#34;&#34;基于语义边界进行分块（更智能）&#34;&#34;&#34; # 按段落分割 paragraphs = text.split(&#39;\n\n&#39;) chunks = [] current_chunk = &#34;&#34; current_size = 0 for para in paragraphs: para_size = len(para.split()) # 简化的token估计 # 如果当前块加上新段落不会太大，合并 if current_size + para_size &lt;= self.chunk_size: current_chunk += &#34;\n\n&#34; + para if current_chunk else para current_size += para_size else: # 保存当前块，开始新块 if current_chunk: chunks.append(current_chunk.strip()) current_chunk = para current_size = para_size # 添加最后一个块 if current_chunk: chunks.append(current_chunk.strip()) return chunks 分块策略的选择：
固定大小分块：简单快速，但可能在句子中间截断 语义分块：尊重文档结构（段落、章节），保持语义完整性 滑动窗口：使用重叠区域避免信息丢失 递归分块：先按大结构（章节）分，再细分，适合长文档 向量化与索引 from typing import List, Dict import numpy as np from sentence_transformers import SentenceTransformer class EmbeddingEngine: &#34;&#34;&#34;文本向量化引擎&#34;&#34;&#34; def __init__(self, model_name: str = &#34;sentence-transformers/all-MiniLM-L6-v2&#34;): &#34;&#34;&#34; 初始化嵌入模型 常用模型选择： - all-MiniLM-L6-v2: 轻量级，速度快，384维 - all-mpnet-base-v2: 性能更好，768维 - text-embedding-ada-002: OpenAI模型，1536维 &#34;&#34;&#34; self.model = SentenceTransformer(model_name) self.dimension = self.model.get_sentence_embedding_dimension() def embed_documents(self, texts: List[str]) -&gt; np.ndarray: &#34;&#34;&#34;批量向量化文档&#34;&#34;&#34; # 使用批处理提高效率 embeddings = self.model.encode( texts, batch_size=32, show_progress_bar=True, convert_to_numpy=True ) return embeddings def embed_query(self, query: str) -&gt; np.ndarray: &#34;&#34;&#34;向量化查询&#34;&#34;&#34; return self.model.encode(query, convert_to_numpy=True) 2. 检索流程 (Retrieval Pipeline) 检索是RAG的核心，目标是找到与用户查询最相关的文档片段。
向量数据库集成 from typing import List, Tuple import chromadb from chromadb.config import Settings class VectorStore: &#34;&#34;&#34;向量数据库封装&#34;&#34;&#34; def __init__(self, collection_name: str = &#34;documents&#34;): &#34;&#34;&#34;初始化Chroma向量数据库&#34;&#34;&#34; self.client = chromadb.Client(Settings( chroma_db_impl=&#34;duckdb+parquet&#34;, persist_directory=&#34;./chroma_db&#34; )) self.collection = self.client.get_or_create_collection( name=collection_name, metadata={&#34;hnsw:space&#34;: &#34;cosine&#34;} # 使用余弦相似度 ) def add_documents( self, texts: List[str], embeddings: np.ndarray, metadatas: List[Dict] = None ): &#34;&#34;&#34;添加文档到向量库&#34;&#34;&#34; ids = [f&#34;doc_{i}&#34; for i in range(len(texts))] self.collection.add( ids=ids, embeddings=embeddings.tolist(), documents=texts, metadatas=metadatas or [{}] * len(texts) ) def search( self, query_embedding: np.ndarray, top_k: int = 5 ) -&gt; Tuple[List[str], List[float], List[Dict]]: &#34;&#34;&#34; 检索最相关的文档 Returns: documents: 检索到的文本列表 distances: 相似度分数列表 metadatas: 元数据列表 &#34;&#34;&#34; results = self.collection.query( query_embeddings=[query_embedding.tolist()], n_results=top_k ) return ( results[&#39;documents&#39;][0], results[&#39;distances&#39;][0], results[&#39;metadatas&#39;][0] ) 高级检索技术 1. 混合检索 (Hybrid Search) 结合向量检索和传统关键词检索，可以显著提升检索质量。
from rank_bm25 import BM25Okapi import numpy as np class HybridRetriever: &#34;&#34;&#34;混合检索器：结合向量检索和BM25&#34;&#34;&#34; def __init__(self, vector_store: VectorStore, documents: List[str]): self.vector_store = vector_store self.documents = documents # 初始化BM25 tokenized_docs = [doc.lower().split() for doc in documents] self.bm25 = BM25Okapi(tokenized_docs) def search( self, query: str, query_embedding: np.ndarray, top_k: int = 5, alpha: float = 0.5 ) -&gt; List[Tuple[str, float]]: &#34;&#34;&#34; 混合检索 Args: alpha: 向量检索的权重 (0-1)，1-alpha为BM25权重 &#34;&#34;&#34; # 向量检索 vec_docs, vec_scores, _ = self.vector_store.search( query_embedding, top_k=top_k * 2 # 检索更多候选 ) # BM25检索 tokenized_query = query.lower().split() bm25_scores = self.bm25.get_scores(tokenized_query) # 归一化分数 vec_scores = np.array(vec_scores) vec_scores = (vec_scores - vec_scores.min()) / (vec_scores.max() - vec_scores.min() + 1e-10) bm25_scores = (bm25_scores - bm25_scores.min()) / (bm25_scores.max() - bm25_scores.min() + 1e-10) # 合并分数 combined_scores = {} for doc, score in zip(vec_docs, vec_scores): if doc in self.documents: idx = self.documents.index(doc) combined_scores[doc] = alpha * score + (1 - alpha) * bm25_scores[idx] # 排序并返回top-k sorted_results = sorted( combined_scores.items(), key=lambda x: x[1], reverse=True )[:top_k] return sorted_results 2. 重排序 (Reranking) 使用更强大的模型对初步检索结果进行重新排序。
from sentence_transformers import CrossEncoder class Reranker: &#34;&#34;&#34;重排序器&#34;&#34;&#34; def __init__(self, model_name: str = &#34;cross-encoder/ms-marco-MiniLM-L-6-v2&#34;): &#34;&#34;&#34; 初始化交叉编码器模型 CrossEncoder直接计算query-document对的相关性分数 &#34;&#34;&#34; self.model = CrossEncoder(model_name) def rerank( self, query: str, documents: List[str], top_k: int = 5 ) -&gt; List[Tuple[str, float]]: &#34;&#34;&#34; 重排序文档 Args: query: 用户查询 documents: 候选文档列表 top_k: 返回前k个结果 &#34;&#34;&#34; # 构建query-document对 pairs = [[query, doc] for doc in documents] # 计算相关性分数 scores = self.model.predict(pairs) # 排序 ranked_results = sorted( zip(documents, scores), key=lambda x: x[1], reverse=True )[:top_k] return ranked_results 3. 查询改写 (Query Rewriting) 优化用户查询以提升检索效果。

from typing import List, Dict, Optional import openai class RAGGenerator: &#34;&#34;&#34;RAG生成器&#34;&#34;&#34; def __init__( self, api_key: str, model: str = &#34;gpt-4&#34;, temperature: float = 0.1 ): openai.api_key = api_key self.model = model self.temperature = temperature def build_context( self, documents: List[str], max_tokens: int = 2000 ) -&gt; max_tokens: break context_parts.append(f&#34;[Document {i+1}]\n{doc}\n&#34;) current_tokens += doc_tokens return &#34;\n&#34;.join(context_parts) def generate( self, query: str, retrieved_docs: List[str], system_prompt: Optional[str] = None ) -&gt; Dict[str, any]: &#34;&#34;&#34; 生成答案 Returns: 包含answer和metadata的字典 &#34;&#34;&#34; # 构建上下文 context = self.build_context(retrieved_docs) # 默认系统提示 if system_prompt is None: system_prompt = &#34;&#34;&#34;你是一个专业的AI助手。你的任务是基于提供的参考文档回答用户问题。 重要规则： 1. 只使用参考文档中的信息来回答问题 2. 如果文档中没有相关信息，明确告诉用户&#34;根据提供的文档，我无法回答这个问题&#34; 3. 引用具体的文档内容时，注明来源（例如&#34;根据Document 1...&#34;） 4. 保持回答准确、客观、有条理 5. 不要编造或推测文档中没有的信息&#34;&#34;&#34; # 构建用户消息 user_message = f&#34;&#34;&#34;参考文档： {context} 用户问题：{query} 请基于上述参考文档回答问题。&#34;&#34;&#34; # 调用LLM response = openai.ChatCompletion.create( model=self.model, messages=[ {&#34;role&#34;: &#34;system&#34;, &#34;content&#34;: system_prompt}, {&#34;role&#34;: &#34;user&#34;, &#34;content&#34;: user_message} ], temperature=self.temperature, max_tokens=1000 ) answer = response.choices[0].message.content return { &#34;answer&#34;: answer, &#34;context&#34;: context, &#34;model&#34;: self.model, &#34;tokens_used&#34;: response.usage.total_tokens } def generate_with_citations( self, query: str, retrieved_docs: List[Tuple[str, float]], # (document, score) metadatas: List[Dict] ) -&gt; class RAGSystem: &#34;&#34;&#34;完整的RAG系统&#34;&#34;&#34; def __init__( self, embedding_model: str = &#34;sentence-transformers/all-MiniLM-L6-v2&#34;, llm_model: str = &#34;gpt-4&#34;, api_key: str = None ): # 初始化各个组件 self.loader = DocumentLoader() self.chunker = TextChunker(chunk_size=512, chunk_overlap=50) self.embedder = EmbeddingEngine(embedding_model) self.vector_store = VectorStore() self.reranker = Reranker() self.generator = RAGGenerator(api_key, llm_model) self.documents = [] # 存储原始文档 def ingest_documents(self, file_paths: List[str]): &#34;&#34;&#34; 文档摄入流程 Args: file_paths: 文档文件路径列表 &#34;&#34;&#34; print(&#34;Loading documents...&#34;) all_chunks = [] all_metadatas = [] for file_path in file_paths: # 加载文档 if file_path.endswith(&#39;.pdf&#39;): text = self.loader.load_pdf(file_path) elif file_path.endswith(&#39;.md&#39;): text = self.loader.load_markdown(file_path) else: continue # 预处理 text = self.loader.preprocess(text) # 分块 chunks = self.chunker.chunk_by_semantic(text) # 记录元数据 metadatas = [ {&#34;source&#34;: file_path, &#34;chunk_id&#34;: i} for i in range(len(chunks)) ] all_chunks.extend(chunks) all_metadatas.extend(metadatas) self.documents = all_chunks # 向量化 print(f&#34;Embedding {len(all_chunks)} chunks...&#34;) embeddings = self.embedder.embed_documents(all_chunks) # 索引 print(&#34;Indexing to vector store...&#34;) self.vector_store.add_documents( texts=all_chunks, embeddings=embeddings, metadatas=all_metadatas ) print(f&#34;Successfully ingested {len(file_paths)} documents!&#34;) def query( self, question: str, top_k: int = 5, use_reranking: bool = True ) -&gt; Dict[str, any]: &#34;&#34;&#34; 查询RAG系统 Args: question: 用户问题 top_k: 返回的文档数量 use_reranking: 是否使用重排序 Returns: 包含答案和元数据的字典 &#34;&#34;&#34; print(f&#34;Query: {question}&#34;) # 1. 向量化查询 query_embedding = self.embedder.embed_query(question) # 2. 检索 print(&#34;Retrieving relevant documents...&#34;) retrieved_docs, scores, metadatas = self.vector_store.search( query_embedding, top_k=top_k * 2 if use_reranking else top_k ) # 3. 重排序（可选） if use_reranking: print(&#34;Reranking documents...&#34;) reranked = self.reranker.rerank( question, retrieved_docs, top_k=top_k ) retrieved_docs = [doc for doc, _ in reranked] scores = [score for _, score in reranked] # 4. 生成答案 print(&#34;Generating answer...&#34;) result = self.generator.generate_with_citations( question, list(zip(retrieved_docs, scores)), metadatas[:len(retrieved_docs)] ) return result # 使用示例 if __name__ == &#34;__main__&#34;: # 初始化系统 rag = RAGSystem( api_key=&#34;your-openai-api-key&#34; ) # 摄入文档 rag.ingest_documents([ &#34;./docs/rag_paper.pdf&#34;, &#34;./docs/llm_guide.md&#34;, &#34;./docs/vector_db_intro.pdf&#34; ]) # 查询 result = rag.query( &#34;什么是RAG？它解决了什么问题？&#34;, top_k=3 ) print(&#34;\nAnswer:&#34;, result[&#39;answer&#39;]) print(&#34;\nSources:&#34;, result[&#39;sources&#39;]) RAG系统的优化策略 1. 提升检索质量 查询扩展与改写 class AdvancedQueryProcessor: &#34;&#34;&#34;高级查询处理器&#34;&#34;&#34;
